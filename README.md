# PFUM — Portfolio Ultra Marine

Ruprous（ラプラス）のポートフォリオサイトです。

**https://ruprous.me**

デザインと映像の制作実績（Work）と、制作したツールや実験（Lab）をまとめています。
フリーランスのデジタルクリエイターとして、グラフィック・ロゴ・映像などを制作しています。

## 特徴

- **群青と紙色のデザイン** — 群青 `#0736FE` と紙のようなグレーを基調に、ピル型のUI、ピクセル書体の見出し、ゼロックス風のノイズ、網点（ハーフトーン）を組み合わせています。
- **作品のステッカー** — トップでは、全作品からランダムに選んだ4枚が、青白の網点処理を施したステッカーとして重なります。シャッフルボタンで入れ替えられます。
- **作品一覧と詳細** — ジャンルで絞り込める一覧、YouTube埋め込み、画像の拡大表示（キーボード・スワイプ対応）。
- **軽量** — WebGLや常時動くアニメーションは使わず、静的なCSSで構成しています。画像はビルド時に WebP の縮小版を生成して配信します。
- **レスポンシブ** — PCからスマートフォンまで対応しています。

## 技術

React 19 / TypeScript / Vite / React Router。画像の変換に sharp。GitHub Pages で公開しています。
